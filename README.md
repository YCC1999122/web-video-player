# Web Video Player

一个独立开发的轻量级网页视频播放器。基于原生 HTML5 Video API，零依赖、零框架，纯前端实现。

## 特性

- 纯原生实现，不依赖任何第三方库
- 自定义控件：播放/暂停、进度条、音量、倍速、全屏
- 播放列表管理，支持多视频切换
- **字幕同步**：CC 按钮，按时间戳显示示例字幕
- **弹幕系统**：弹幕开关、彩色弹幕（白/蓝/粉/黄/绿/紫）、弹幕输入框、示例弹幕按视频时间自动触发
- 键盘快捷键支持（空格暂停、左右快进、上下音量、F 全屏、C 字幕、D 弹幕）
- 玻璃态 UI + 渐变边框，浅色主题
- 响应式布局，适配桌面与移动端
- 视频信息展示（标题、作者、观看数）

## 使用方法

直接在浏览器中打开 `index.html` 即可。也可以部署到任意静态托管服务（GitHub Pages、Vercel、Netlify 等）。

## 键盘快捷键

| 按键 | 功能 |
| --- | --- |
| `Space` | 播放 / 暂停 |
| `←` / `→` | 快退 / 快进 5 秒 |
| `↑` / `↓` | 音量增减 |
| `F` | 全屏切换 |
| `M` | 静音切换 |
| `C` | 字幕开关 |
| `D` | 弹幕开关 |
| `Enter` | （弹幕输入框内）发送弹幕 |
| `0-9` | 跳转到 0%-90% 进度 |
