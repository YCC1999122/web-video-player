# Web Video Player

一个独立开发的网页视频概念演示平台。基于原生 HTML5 Video API，零依赖、零框架，纯前端实现。

> 这不是一个普通播放器，而是一个展示视频交互新可能的概念平台。三大创新功能均为概念演示，真实实现需要 AI 视觉识别 / 音频频谱分析 / 视频内容理解 等技术支撑。

## 三大创新概念

### 01 · 视频购物车 · 拖拽即识别
暂停视频后，画面上会出现一个可拖拽的购物车图标。把它拖到视频里任意物体上，松开后弹出该物体的商品识别卡片 — 名称、款式、价格、购买渠道、相似商品。把"看视频"变成"逛视频"。

### 02 · 声纹预警 · 看见声音的形状
进度条上方显示整段视频的音频波形趋势，让用户在播放前就能预判哪一刻声音会骤然变大。戴耳机的用户不再被突然的爆炸声 / 喊叫惊吓 — 红色标记是"此处音量骤增"的预警点。

### 03 · AI 内容搜索 · 从标签到内容
传统视频搜索靠人工标签 — 但标签写不全、写不准。AI 内容搜索把整段视频"读"一遍，提取出所有出现过的关键事物（西瓜、乒乓球、恐龙、吃火锅…），哪怕标签里没写，也能精准命中。

## 其他特性

- 纯原生实现，不依赖任何第三方库
- 自定义控件：播放/暂停、进度条、音量、倍速、全屏
- 播放列表管理，支持多视频切换
- **字幕同步**：CC 按钮，按时间戳显示示例字幕
- **弹幕系统**：弹幕开关、彩色弹幕（白/蓝/粉/黄/绿/紫）、弹幕输入框、示例弹幕按视频时间自动触发
- 键盘快捷键支持（空格暂停、左右快进、上下音量、F 全屏、C 字幕、D 弹幕）
- 玻璃态 UI + 渐变边框，浅色主题
- 响应式布局，适配桌面与移动端
- 视频信息展示（标题、作者、观看数）

## 使用方法

直接在浏览器中打开 `index.html` 即可。也可以部署到任意静态托管服务（GitHub Pages、Vercel、Netlify 等）。

## 键盘快捷键

| 按键 | 功能 |
| --- | --- |
| `Space` | 播放 / 暂停 |
| `←` / `→` | 快退 / 快进 5 秒 |
| `↑` / `↓` | 音量增减 |
| `F` | 全屏切换 |
| `M` | 静音切换 |
| `C` | 字幕开关 |
| `D` | 弹幕开关 |
| `Enter` | （弹幕输入框内）发送弹幕 |
| `0-9` | 跳转到 0%-90% 进度 |
